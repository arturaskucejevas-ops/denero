Kuriame ir pritaikome **internetines svetaines**, **verslo portalus** ir **CRM sistemas**, kurios susietos su jūsų ERP ir kitomis sistemomis.

## Internetinės svetainės ir verslo portalai

Kuriame greitas, saugias ir paieškos sistemoms optimizuotas svetaines bei klientų ir partnerių portalus (ASP.NET Core, React, Microsoft Power Pages), kuriuose klientai gali pateikti užsakymus, užklausas ar peržiūrėti dokumentus.

## CRM sistemos

Diegiame ir pritaikome **Microsoft Dynamics 365 CRM** ir **Dataverse** sprendimus: klientų ir kontaktų valdymą, pardavimų procesą, užklausų ir aptarnavimo valdymą, automatinius priminimus bei ataskaitas.

## Integracijos

Sujungiame svetaines, portalus ir CRM su Dynamics NAV / Business Central, el. paštu, mokėjimų ir kitomis išorinėmis sistemomis, kad duomenys būtų vienoje vietoje.

## Naudojamos technologijos

* HTML5 / CSS3
* JavaScript / TypeScript
* React
* .NET / C#
* ASP.NET Core
* Microsoft Power Pages
* Microsoft Dynamics 365 CRM
* Microsoft Dataverse
* Microsoft SQL Server
* REST API / Web Services
* Azure Cloud
